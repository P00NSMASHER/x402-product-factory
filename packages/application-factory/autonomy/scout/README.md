# Source-backed, unattended candidate scout

Each source-controlled lead in `leads.json` contains a researched buyer workflow hypothesis, two dated public reference URLs, and a mechanically different four-step document lifecycle. The sources provide process context, **not evidence that people will buy**. They were researched on 2026-10-13 from NIST, EPA, and DOE material. No live web crawler, invented testimonials, revenue, or customer claim exists.

The scout **automatically assigns the first three leads to UTC six-hour cycles 75, 76 and 77**, in append-only order, after the 72 curated editions and three exact reviewed blueprints. Newly appended records reserve subsequent slots without drafting `cycle-N.json` by hand. Existing exact-cycle blueprints take precedence, never rearranging later slots. Changing a consumed lead changes its source digest and the verified cycle fails closed. Qualification uses the original strict evidence-date, duplicate-mechanism, requirements and safe-URL gates.

Commands:

```sh
node scripts/scout-app-ideas.js --check
node scripts/scout-app-ideas.js --build --output /absolute/private/build-output
```

The second command assembles, independently runs, and verifies each available candidate as a synthetic local app before reporting a pass. A readiness score describes **technical workflow fit only**, never buyer demand, market validation, security certification, or commercial approval. Honest states distinguish reviewed exact-cycle overrides from independently unverified app ideas.

Automatic research extension is limited to credible source records added by the existing authorized research workflow; no unsupervised model API or indefinite discovery is claimed. Public hosted deployment, emails, paid services, financial activation, signing legally required paperwork, compliance certification and new numbered Product 025+ remain disabled.
