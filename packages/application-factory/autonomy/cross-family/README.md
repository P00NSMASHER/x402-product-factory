# Cross-family hypothesis to full-app manufacturing

Eight structurally different buyer-workflow hypotheses (four quote-to-internal-order, four inventory replenishment) are entered as **problems, triggers and inputs**, not as full application source code. The factory automatically derives validated application recipes, assigns deterministic safe example defaults, compiles independently runnable role-separated applications and tests real SQLite+HTTP lifecycles.

The cited NIST manufacturing and federal acquisition reference pages establish **broad operational context only**. They do not establish market demand, current prices, verified customers, regulatory compliance or real commercial economics. All inventory unit costs are fictional examples; synthetic quote values are user-entered in local tests. Technical-fit scores measure structural readiness only.

    node scripts/manufacture-cross-family-ideas.js --check
    node scripts/manufacture-cross-family-ideas.js --build --quote-output /absolute/private/quotes --inventory-output /absolute/private/inventory

A new source proposal must pass exact schema, safe HTTPS, non-PII, source-date, unique item, novelty and separate-family-kernel validation. The source order remains stable; app identities must not be silently rewritten after reviewed packages exist. New items can be added in the bounded queue, but there is no claim of unrestricted AI generation.

CI independently builds all eight synthetic apps, then subjects them to the private deployment probe. Public hosting, actual payments, checkout, outreach, customer data and new Product 025+ remain blocked.
