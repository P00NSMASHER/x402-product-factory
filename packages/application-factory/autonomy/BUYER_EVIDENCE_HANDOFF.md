# Evidence-to-buyer review across 11 manufactured applications

Run `node scripts/review-factory-opportunities.js --check` to produce a
read-only, source-hashed review queue across the three document ideas
and eight newer quote/inventory workflows.

Every entry names the proposed buyer role, job, trigger, dated public
context links, specific interview question, and falsification standard.
No buyer records, personal contacts, outreach, external API calls, file writes,
purchases, hosting, revenue, or production switches are involved.

**Interpretation:** These are eleven hypotheses supported by engineering
workflow context, **not eleven buyer-validated products**. Mechanical-fit scores
are explicitly not demand scores. Three early conversations per concept is
merely a qualitative discovery suggestion, not a representative sample.
Real buyer evidence and real workflow completion remain unknown until
separately permissioned and independently observed.

After authorized external discovery, operators must obtain consent and
record redacted proof outside this source-only queue. The user retains
customer onboarding, security, financial, and commercial approval gates.
This draft does not change any schedules, credentials, original receipts,
application source, or public deployment state.
